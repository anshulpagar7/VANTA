05 — Honesty

What this does not prove.

A benchmark that cannot state its own limits is marketing. These are in the repository as LIMITATIONS.md, written before the results and updated with them.

Structural limits

  • The world is synthetic. Outcome probabilities were authored, not observed. Where a parameter has a published source it is marked sourced; everything else is marked assumed. A result that survives only at one parameter setting is not a result.
  • The same author wrote the world and the agents. The mitigation is structural rather than a promise: policy code is forbidden from importing the world, checked at the syntax-tree level on every test run. But it is a mitigation, not an elimination.
  • One holdout run. By design, and it stands whatever it says.
  • Five seeds is a small sample. The paired test is what makes an effect this size detectable at all; a marginal result at this sample size should be read as marginal.

The safety claim is narrower than it sounds

"The model cannot manufacture authority" is precise, and it is worth being precise about what it excludes. The boundary bounds what the model may do, not how well it reasons.

A hallucinated diagnosis cannot exceed its permissions. It can still spend a permitted retry, or a permitted customer contact, on a payment that was never recoverable. That is real cost, and it is reported rather than explained away.

There is also no training here, deliberately. The only data available is generated by the frozen world, so fitting a model to it would mean learning the answer key — the exact failure the freeze and the holdout split exist to prevent. Fitting the belief tables from observed outcomes is the obvious next step with real data.

Not modelled

Customer churn as a downstream cost of over-contacting. Seasonal effects. Issuer policy changes over time. Any correlation between payment size and recoverability. Each of these would likely narrow the gap between arms, so the spread here should be read as an upper bound rather than a forecast.

A calibration probe on a single-action budget puts naive retry near 11–12% and an oracle with access to the hidden root cause near 28%. Under the full runner, with up to eight decisions per event, arm B reaches 34.5%. The single-action oracle is a reference point, not a ceiling — an early version of this write-up mistook it for one.
