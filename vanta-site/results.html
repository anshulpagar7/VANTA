What the model actually contributed

B+ and C run the same candidate generation, the same scoring, the same guardrail-aware scheduling and the same abstention rule, against the same seeds. Only the diagnosis differs, so the gap between them is the model's isolated contribution.

The test that nearly killed this result

The first version of the report declared the model had earned its place whenever its mean beat B+. On development data the gap was ₹24,522 while each arm's own interval was over ₹85,000 — by that reading it was indistinguishable from noise, and the report would have been overclaiming.

The correct comparison is the paired per-seed difference, because both arms run on identical seeds. Common random numbers cancel most of the shared variance, and the paired interval came out at ₹18,918 — narrower than the effect. It survived, then strengthened out of sample.

Two tests now encode the distinction: a consistent small edge is significant, and a noisy edge the size of its own mean is not. The second one exists specifically to catch the mistake the first version made.
